2logical ID — iPhone Home Screen App

Contents:
- index.html
- manifest.webmanifest
- service-worker.js
- assets/

Use:
1. Upload the entire folder contents to any HTTPS host (GitHub Pages, Netlify, Cloudflare Pages, etc.).
2. Open the HTTPS URL in Safari on iPhone.
3. Tap Share > Add to Home Screen.
4. Launch “2logical ID” from the Home Screen.

The badge flips front/back by tapping it and is cached for offline use after the first successful load.
